# Rob's Precons

One page listing the Commander precons Rob lends out. Tap a deck to see what it does.

- `index.html` is the page GitHub Pages shows.
- `decks.tsv` lists the decks: name, set, commanders and colors.
- `build.py` makes `index.html` from `decks.tsv`: `python3 build.py decks.tsv index.html`
- `.nojekyll` tells GitHub Pages to show the files as they are.

This is still a mockup: the descriptions are placeholder text.
